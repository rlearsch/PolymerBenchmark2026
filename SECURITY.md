# Security Policy

## Reporting a vulnerability

Please do not report suspected security vulnerabilities in a public GitHub
issue. Instead, email learsch1 at llnl dot gov with:

- a description of the issue and its potential impact;
- the affected file, component, or workflow;
- steps to reproduce it; and
- any suggested mitigation, if available.

The project will acknowledge reports within seven calendar days and will work
with the reporter on an appropriate disclosure timeline.

## Scope

This policy covers vulnerabilities in the code and configuration maintained in
this repository. It does not cover vulnerabilities in external services,
third-party datasets, or externally hosted models; those should also be
reported to their respective maintainers.

Ordinary bugs, documentation issues, feature requests, and questions should be
reported through GitHub Issues.
